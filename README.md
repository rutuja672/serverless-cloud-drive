# serverless-cloud-drive
Serverless Cloud Drive with Health Monitoring using Cloud Computing concepts.

## 📌 Project Overview

This project demonstrates a cloud-based file storage system built using serverless architecture concepts.

Users can upload files, retrieve stored files, and monitor system health through dedicated APIs.

---

## 🚀 Features

- Secure File Upload
- File Retrieval
- Health Monitoring Endpoint
- Lightweight Cloud Storage Simulation
- REST API Based Architecture

---

## 🛠️ Tech Stack

- Python
- Flask
- Cloud Computing
- Serverless Architecture
